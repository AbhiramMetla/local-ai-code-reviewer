
# Local AI Code Review Assistant

An AI-powered code review application that uses a locally running language model to identify potential bugs, code-quality issues, and security concerns.

## Planned Features

- Analyze submitted source code
- Identify potential bugs and security risks
- Provide structured review findings
- Suggest code improvements
- Interactive web interface
- Automated tests

## Technology Stack

- Python
- Ollama
- Streamlit
- Pydantic
- pytest

## Project Status

Currently in the initial setup phase.
